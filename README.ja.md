## 🎀 わたしについて

<table>
<tr>
<td width="64%" valign="middle">

こんにちは、**YumeSKR** です 🌸

ひらめきと好奇心を、小さな作品に変えていくのが好きな人です。コードも、デザインも、夕焼けも、かわいいものも、ぜんぶ日々の栄養になっています。

ここには少しずつ、いろんなものが住みはじめます。芽を出したばかりのアイデア、学びながら残したメモ、そして少しずつ育っていくプロジェクト。どうぞ気軽にのぞいていってくださいね。

- 🌷 **いま取り組み中**：頭の中のアイデアを小さいステップに分けて、ひとつずつ形にすること
- 🧸 **好きな雰囲気**：すっきりしていて、やさしくて、ちょっとかわいい
- 📚 **勉強中**：新しいツール、新しい書き方、もっと素敵に見せるコツ
- 💌 **ひとこと**：ゆっくりで大丈夫。少し前に進めたらそれで十分
